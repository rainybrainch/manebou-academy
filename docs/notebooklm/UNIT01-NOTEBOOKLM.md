## よくある誤解と説明方法（講師用）

### 誤解1: 「お金 = ただ持っていればいい」

**子どもの誤解**：「給料をもらったら、全部ポケットに入れておけばいい」

**説明方法**：
- 「銀行に預けるとどうなるか知ってる？」
- 「じつは『どこに置くか』が大事なんだ。銀行に預けるのと、手元に置くのでは、将来が変わることもある」
- ゲーム内でも「現金で持っているだけ」と「株に変える」では結果が変わることを見せる

### 誤解2: 「株 = ギャンブル」

**子どもの誤解**：「株って『当たるか外れるか』のギャンブルでしょ？」

**説明方法**：
- 「『短期の値動きに賭ける』ならギャンブルに近い」
- 「『この会社は大丈夫か』『これからも成長するか』を調べて選ぶ。それが『投資』」
- 「根拠があるか、ないか。その差が大きい」

### 誤解3: 「資産は『寝かせておくと増える』」

**子どもの誤解**：「資産を持っていれば、何もしなくても増える」

**説明方法**：
- 「資産は『現金』『預金』『株』『土地』など、いろいろな種類がある」
- 「増えるものもあれば、価値が下がるものもある」
- 「だから『何を資産として持つか』を考えることが大事」

### 誤解4: 「配当は『銀行の利息のように、必ずもらえる』」

**子どもの誤解**：「株を持っていれば、毎回配当がもらえる」

**説明方法**：
- 「配当は、会社が『利益が出たから、株主に分けます』と決めた時だけ」
- 「利益が出なかった年は、配当がゼロの場合もある」
- 「詳しくはUNIT6『決算と配当』で学びます」

### 誤解5: 「『会社を選ぶ』って何を基準に選ぶの？」

**子どもの誤解**：「『いい会社を選ぶ』と言われても、何を見たらいいの？」

**説明方法**：
- 「段階がある。①『好きなお店』『よく見かける会社』から興味を持つ」
- 「②『その会社は何をしている？』『商品は売れてる？』を調べる」
- 「③『これからも成長しそうか？』『つぶれる心配はないか？』を考える」
- ゲーム内で「なぜこの会社を選んだ？」と理由を言わせることが、この思考の練習になる

### 誤解6: 「『投資したら、必ず勝てる』」

**子どもの誤解**：「調べて選べば、お金が増える」

**説明方法**：
- 「調べて選ぶ『投資』でも、損をする可能性がある」
- 「世の中は不確実。だからこそ『なぜこの会社か』を考えることが大事」
- 「大人も『完全に勝つ』ことはできない。だから『リスク』を学ぶ必要がある」

## よくある質問（FAQ）【講師用検索資料】

### 【子どもからよくある質問】

**Q1: このゲーム、本当の株ですか？**
A: いいえ。ゲーム内の仮想の株です。でも『本当の株の仕組みを体験する』ためのゲームです。

**Q2: なぜゲームのルール、難しいんですか？**
A: 最初は「こういう流れなんだ」くらいで大丈夫。12回のUNITで徐々にルールが増えます。野球のルールも『最初はわからない』けど『やっていると分かる』のと同じです。

**Q3: なぜ『勝つ』ことが目的じゃないんですか？**
A: 社会人も「誰かと競争して勝つ」のではなく、「自分の資産をどう増やすか」に集中しています。このゲームで『投資判断』を学ぶことで、大人になった時に『社会で必要なスキル』が身につきます。

**Q4: 配当ってなぜもらえるんですか？**
A: 会社が儲かったから。会社が言うには「オーナーの皆さん、ありがとうございます。利益を分けます」ということです。でも『すべての年に配当がもらえる』わけではありません。詳しくはUNIT6で学びます。

**Q5: 株を持っていると『何もしなくてもお金がもらえる』んですか？**
A: はい。株を持っているだけで「配当」がもらえることがあります。だから「お金を寝かせておいても『条件によって』増える可能性がある」と言うんです。

**Q6: 親も株を持っているんですか？**
A: 持っている親も多いです。年金も「過去に投資した」お金が増えて戻ってきたものです。だから「投資」は大人も子どもも大事なんです。

**Q7: 株を売る時って、いつ売ったらいいんですか？**
A: いい質問ですね。その判断が「投資家の力」です。UNIT7で詳しく学びます。

**Q8: お金がなくても生きていけますか？**
A: 昔は「物々交換」で生活していました。でも今は「社会全体がお金で成り立っている」から、お金が必要です。

**Q9: なぜ人は『資産を増やしたい』と思うんですか？**
A: 「将来の不安を減らしたい」「今よりも豊かな生活がしたい」「子どもの教育費を用意したい」など、理由は人それぞれです。

**Q10: このゲームで学んだことって、本当に役に立つんですか？**
A: はい。大人になって「給料をもらう」「銀行に預ける」「株を買う」ときに、このゲームで学んだ『判断基準』が役に立ちます。

### 【保護者からよくある質問】

**Q1: この授業は、本当に『株式投資』を学べるのですか？**
A: はい。UNIT12までを通じて「会社を見分ける方法」「リスク管理」「判断基準」など、『本当の投資家が考えること』を全て体験します。ゲーム内では『実際のお金を使わない』ので安全に体験できます。

**Q2: 子どもに『株』を学ばせても大丈夫ですか？**
A: はい。金融リテラシーは「早い段階」で学ぶほど効果的です。このゲームでは「実際のお金を使わない」ので安全に体験できます。

**Q3: 家庭での『宿題のサポート』は何をすればいいですか？**
A: 
1. 「親の給料がなぜ大事なのか」についての質問に答える
2. 「家計簿」を一緒に見ながら「お金の流れ」について話す
3. ニュースで「株」や「企業」の話題が出たら「あ、これだ」と指摘する

**Q4: 子どもが『親も株を持っているのか』と聞いてきました。何と答えたらいいですか？**
A: 実際の状況を教えてください。投資していなくても大丈夫：「親が投資していなくても、『銀行預金の利息』『生命保険の仕組み』など、同じ原理を使っています」と説明できます。

**Q5: 『配当』について、子どもから質問されたら何と答えたらいいですか？**
A: 「『配当 = 会社が儲かったから、その利益をオーナーに分け合う』『銀行の利息と似ているが『必ずもらえるわけではない』という違きがあります』」と説明してください。

**Q6: 『リスク』って、子どもに説明するのは早くないですか？**
A: いいえ。「『リスク = 変動する可能性がある』」という理解は、お金を扱う時に最も大事です。早い段階で体験させることをお勧めします。

**Q7: このゲーム以外に、家庭で『金融教育』をするには？**
A: 
1. ニュースで「株価」「企業」の話題に反応する
2. 「親が給料をもらう」「銀行に預ける」という「現実」を見せる
3. 将来「実際の株を買う」前に、このゲームで判断基準を身につけさせる

**Q8: 『子どもが失敗する（資産が減る）』ことは大丈夫ですか？**
A: はい。むしろ「ゲーム内での失敗」が「現実での成功」につながります。「なぜ失敗したのか」を考える機会が宝物です。

**Q9: このコース修了後、『次は何をしたらいいですか？**
A: UNIT12終了後、「中級・上級コース」で「銀行・金利」「NISA・投資信託」「税金」などを学べます。

**Q10: 親自身が『金融知識がない』場合、どうしたらいいですか？**
A: 塾の「親向け説明会」で「このコースの目的」「家庭でのサポート方法」「親自身の金融知識」について説明する機会があります。

## UNIT01 用語集（NotebookLM検索用）

| 用語 | 簡潔説明 | 具体例 |
|------|---------|--------|
| **お金** | 物やサービスを交換するための社会全体での「約束」 | コンビニでジュースを買う時に100円を払う |
| **資産** | 個人や会社が持つ経済的な価値のあるもの | 現金、預金、株、土地など |
| **給料** | 働いた対価としてもらうお金（一時的） | 親が毎月末に銀行口座に受け取るお金 |
| **利息** | 銀行に預けたお金に対する条件付き報酬 | 100万円を銀行に預けると、条件により年0.1%の利息がつく可能性 |
| **株** | その会社のオーナーになるチケット | ユニクロの株 = ユニクロのオーナーの一人になる |
| **配当** | 会社が利益などをもとに株主へ分けると決めたお金 | 会社が10億円儲かったら「1000万円の配当」を分配することを決める |
| **投資** | 会社の事業・価値・将来性などを調べ、成長や利益を期待してお金を出す行動 | 「この会社は成長しそう」と判断して株を買う |
| **会社** | 人々が集まって製品やサービスを作る組織 | トヨタ（自動車）、ユニクロ（服）、任天堂（ゲーム） |
| **経営** | 会社をどう運営するかの判断 | 「新しい製品を開発する」「海外に進出する」「配当を決める」 |
| **リスク** | 変動する可能性がある度合い | ベンチャー企業 = 高リスク（100倍になるか、ゼロになるか） |
| **現金化** | 資産を現金に変える行動 | 株を売ってお金に変える、銀行から預金を引き出す |
| **市場** | 物やサービスが「買い手」と「売り手」で交換される場所 | 株式市場（株を買う・売る場所）、野菜市場 |

## つまずきポイント対応（講師用）

| 「良い会社って何？」 | 判断基準がわからない | 「①好きなお店から興味を持つ。②その会社が何をしているか調べる。③成長しそうか考える」の3段階を説明 |

## 発展学習（もっと学びたい子ども向け）

### 関連UNIT

- **UNIT2: 会社を知ろう** → UNIT1で「会社を選ぶ」ことを学んだ子どもが「会社にはそれぞれ役割がある」ことを学べる
- **UNIT4: 理論株価と株価** → UNIT1で「会社を選ぶ」ことを学んだ子どもが「実際にどう価値を判定するか」を学べる
- **UNIT6: 決算と配当** → UNIT1で「配当を受け取れる場合がある」ことを学んだ子どもが「配当の仕組み」を深く学べる
- **UNIT7: 株価はなぜ変わる？** → UNIT1で「市場」の概念を理解した子どもが「変動の理由」を学べる
- **UNIT8: リスクと分散投資** → UNIT1で「資産」の概念を理解した子どもが「複数資産を持つ意義」を学べる

### 現実社会との関連事例

- **銀行**: 親が「給料」を銀行に預ける瞬間 / ATMで「利息」を確認 / 「定期預金」の話
- **ニュース**: 「●●会社の売上が前年比20%増加」/ 「有名企業が新製品を発表」/ 「●●業界が不況」
- **家族の会話**: 親が「給料日」について話す / 祖父母が「年金」について話す / 親が「子ども貯金」について話す

### おすすめニュース・トピック

**初心者向け**:
- 「トヨタの営業利益が過去最高」 → 「いい会社 = 利益が出ている」
- 「ユニクロが海外展開」 → 「会社が成長している」
- 「Apple が新しいスマートフォン発表」 → 「新商品 = 売上が期待できる」

**中級向け**:
- 「ソフトバンクの配当が減少」 → 「配当 = 会社の業績に連動」
- 「電気自動車シフトで自動車業界が変革」 → 「市場の変化」
- 「円安で日本企業の輸出が増加」 → 「為替変動」

**観察する視点**:
- 「なぜこのニュースが出たのか？」
- 「これは『いい企業』『悪い企業』のどちらの出来事か？」
- 「この情報が株価にどう影響するか？」

## 授業終了チェック（講師用評価方法）

UNIT1が理解できたかを、以下の3観点で確認します。

### 1. 説明できるか（Knowledge）

講師が以下を聞いて、子どもが「自分の言葉で説明」できるか：

```
□ 「お金って何のためにあるんですか？」
  期待される説明：「物やサービスを交換する時に必要」

□ 「資産ってなんですか？」
  期待される説明：「今持っている価値あるもの」

□ 「株を持つってどういうことですか？」
  期待される説明：「その会社のオーナーになる」

□ 「このゲームの目的って何ですか？」
  期待される説明：「『お金がどう流れるか』『選択がどんな結果につながるか』を学ぶ」

□ 「投資って何ですか？」
  期待される説明：「会社の事業や価値を調べて、成長を期待してお金を出すこと」
```

**判定**: 3個以上「説明できた」= 合格

### 2. 考えられるか（Thinking）

講師が以下を聞いて、子どもが「理由付けして考える」か：

```
□ 「この会社の株、買いたいと思いますか？その理由は？」
  期待される思考：「この会社は商品がよく売れてるから成長しそう」

□ 「なぜ親は『給料をぜんぶ使わない』のだと思いますか？」
  期待される思考：「将来のために『資産に変える』から」

□ 「『現金で持っているだけ』と『株に変える』だったら、どちらが『チャンス』が大きいですか？」
  期待される思考：「株 = 価値が大きく変わる可能性がある」

□ 「もし『好きな会社の株』と『つぶれなさそうな会社の株』があったら、どちらを選びますか？」
  期待される思考：「好きだけど『つぶれたら怖い』から『安全な方を選ぶ』」

□ 「調べて選んでも、損をすることがあるって聞きましたが、本当ですか？」
  期待される思考：「本当。だから『なぜこの会社か』を考えることが大事」
```

**判定**: 3個以上「理由付けして考えた」= 合格

### 3. 質問できるか（Curiosity）

子どもが「自分から質問を出す」か観察：

```
□ 「この会社の株、いくらで買うんですか？」
  → 判定：「価格」に興味 = Good

□ 「配当って、いつもらえるんですか？」
  → 判定：「タイムライン」に興味 = Good

□ 「親が買っている株って、いくら儲かってますか？」
  → 判定：「現実との連動」に興味 = Very Good

□ 「倒産した会社の株ってどうなるんですか？」
  → 判定：「リスク」に興味 = Very Good

□ 「僕も株を買えますか？」
  → 判定：「実践」に関心 = Excellent
```

**判定**: 1個以上「自分から質問が出た」= 合格

### 総合判定フロー

```
【説明できるか】×【考えられるか】×【質問できるか】

✅✅✅ 十分に理解できた：「UNIT1の内容が理解できている」
  → UNIT2へスムーズに進める
  → ゲーム中も「なぜこう判断するのか」が自分で考えられる

✅✅❌ よく理解できた：「基本理解 + 思考あり」
  → UNIT2でも「詳しい説明」を用意すれば大丈夫
  → 質問する習慣が出ると、さらに理解が深まる

✅❌❌ もう少し考えてみよう：「説明は聞いてるが、思考が浅い」
  → UNIT2の導入で「前回のおさらい」を入れる
  → ゲーム中に「なぜこう判断したのか」を丁寧に問う

❌❌❌ 講師と一緒に確認しよう：「説明が十分に理解できていない」
  → 個別フォロー / 保護者との相談を検討
  → UNIT2開始時に「UNIT1の重要部分」を再度説明
```
