# NotebookLM 資料ガイド

## このディレクトリについて

このディレクトリ（`docs/notebooklm/`）には、**講師向けの補助資料**を保存しています。

## 重要な原則

### 正式な教材データはTypeScript

```
正式なデータ元： src/data/course-zai-12unit.ts
```

UNIT1～12の教材は、**TypeScript で一元管理** されています。

- タイトル、テーマ、学習目標
- 時間配分
- キーワード説明
- 先生用ガイド
- ワークシート
- クイズ

### NotebookLM資料の役割

このフォルダの Markdown ファイルは、**講師が授業準備時に検索・参照するための補助資料** です。

- TypeScript ファイルとの重複を避ける
- 検索性を優先（NotebookLMで「よくある質問」を検索しやすくする）
- 講師が実行時に確認する情報を掲載

## ファイル一覧

| **UNIT01-NOTEBOOKLM.md** | UNIT1の講師用60分授業フロー、FAQ、つまずき対応、用語集 | 授業準備・授業中の対応・保護者対応 |
| **UNIT02-NOTEBOOKLM.md** | （準備中） | UNIT2公開時に追加 |

## 使用方法

### 講師がNotebookLMを検索する場面

1. **授業準備**: 「このUNITの60分フロー、確認したい」
   → `UNIT01-NOTEBOOKLM.md` の「60分授業進行表」を参照

2. **授業中の対応**: 「子どもがこう聞いてきた。どう答えたらいい？」
   → `UNIT01-NOTEBOOKLM.md` の「よくある質問」を検索

3. **つまずき対応**: 「子どもがこんなことで困ってる」
   → `UNIT01-NOTEBOOKLM.md` の「つまずきポイント対応」を参照

4. **保護者対応**: 「親から『配当について説明してほしい』と連絡がきた」
   → `UNIT01-NOTEBOOKLM.md` の「保護者からよくある質問」を参照

### 講師がNotebookLMを使わない場面

- 子どもへの説明：TypeScript データの概要を講師が説明する
- ゲーム中の確認：準備段階で対応済み
- 新しい内容を学ぶ：TypeScript が正式データ

## 誤りを見つけた場合

1. **TypeScript ファイルとの矛盾**
   - TypeScript ファイル（`src/data/course-zai-12unit.ts`）が正式版
   - Markdown に矛盾や誤りがあれば、TypeScript を基準に修正

2. **Markdown だけの誤り**
   - このファイルを直接修正
